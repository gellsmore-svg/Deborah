# Psychological: Attentional Bias

Descriptive model of select/sustain/shift/bias. Distinct from REGULATION
[TARGET: attention], which is using attention to change emotion.

## CONTEXT

- **Individual**: Person allocating limited attention.
- **Field**: External display or internal stream.
- **Bias**: Preferential select/sustain toward threat, reward, or salient patches.

## REQUIREMENTS

```
R1. Attention as process is not the same as attentional emotion-regulation. [MUST]
R2. Bias can be toward threat or toward reward. [MUST]
R3. Shift failure is a MODE, not a new construct. [SHOULD]
R4. Descriptive only. [MUST]
```

## OUTCOMES

A filtered field: some options never enter choice because they were not seen.

## PROCESS — Formal

```
PROCESS BiasedAttend (INPUT: field of cues; OUTPUT: selected subset)
  1. ATTENTION [MODE: select] among available cues. [COGNITIVE]
  2. ATTENTION [MODE: bias] toward threat or reward patches. [COGNITIVE]
     CONDITION_MAP: RDoC Cognitive Systems attention / Negative Valence potential threat
  3. ATTENTION [MODE: sustain] on the selected patch. [COGNITIVE]
  4. ATTENTION [MODE: shift] fails or succeeds toward alternatives. [COGNITIVE]
  5. APPRAISAL [TYPE: primary] of only what was seen. [APPRAISAL]
  6. EMERGENT [TYPE: psychological]
```

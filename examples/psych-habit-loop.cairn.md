# Psychological: Habit Loop (cue–routine–reward)

Descriptive model of an individual cue–routine–reward loop. Distinct from
organisational REINFORCEMENT (culture/ritual/metric) and from BE NUDGE incentives.

## CONTEXT

- **Individual**: Person whose behaviour has become cue-driven.
- **Cue**: Discriminative stimulus (place, time, device, affect).
- **Routine**: The chained act.
- **Reward**: Immediate consequence that stamps the loop.

## REQUIREMENTS

```
R1. Name cue, routine, and reward as separate phases. [MUST]
R2. Do not substitute org REINFORCEMENT for an individual loop. [MUST]
R3. Reward may be relief (negative reinforcement) not only pleasure. [SHOULD]
R4. Descriptive only — not an addiction treatment protocol. [MUST]
```

## OUTCOMES

A more automatic routine given the cue, or a weakened loop if reward is absent.

## PROCESS — Formal

```
PROCESS HabitLoop (INPUT: cue in context; OUTPUT: routine fired or withheld)
  1. ATTENTION [MODE: select] lands on the cue. [COGNITIVE]
  2. HABIT [PHASE: cue] of the context (time, place, device). [BEHAVIORAL]
     CONDITION_MAP: RDoC sensorimotor habit / Positive Valence reward learning
  3. HABIT [PHASE: routine] of the chained act. [BEHAVIORAL]
  4. HABIT [PHASE: reward] immediate stamp (pleasure or relief). [MOTIVATIONAL]
  5. FEEDBACK [FROM: reward; VIA: strengthened cue] to future selection.
  6. EMERGENT [TYPE: psychological]

  ITERATE [UNTIL: cue stops or reward is absent]
```
